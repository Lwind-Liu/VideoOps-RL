# 全链路参与与学习路线

目标不是“仓库看起来完整”，而是你能独立解释每一层为什么存在、亲手运行关键步骤、读懂失败轨迹，并能修改实现。

## 固定协作方式

每个阶段都按以下顺序进行：

1. 先定义问题、输入、输出和验收标准；
2. 你参与数据或架构选择；
3. 一起实现最小版本；
4. 实际运行并查看中间产物；
5. 人工分析至少一个成功案例和一个失败案例；
6. 你用自己的话复述，再进入下一阶段。

## S0：任务与证据协议

你需要掌握：

- 为什么直接把整段视频交给 VLM 不够；
- 什么是状态、动作、轨迹、reward 和 episode；
- 为什么最终答案正确不等于证据正确；
- `Segment`、`Task`、`Observation` 分别表达什么。

动手产物：手工构造一条三片段任务，执行一次成功轨迹和一次失败轨迹。

## S1：真实视频和统一时间轴

你需要掌握：

- FFmpeg 解复用、帧率、PTS/DTS 和毫秒时间戳；
- 镜头、字幕、关键帧如何对齐；
- 固定切片为什么可能切断对话和事件。

动手产物：处理一段 5—10 分钟公开视频，输出 `media.json`、`shots.jsonl`、`utterances.jsonl` 和关键帧目录。

## S2：单 Agent baseline

你需要掌握：

- 均匀采样、智能选帧和检索式采样的区别；
- VLM 输入预算如何影响时间定位；
- 严格 JSON Schema、重试和缓存。

动手产物：实现一个不训练的单 Agent，完成查询式片段定位并保存轨迹。

## S3：多 Agent 协作

你需要掌握：

- 为什么角色分工不等于简单地多调用几次模型；
- 每个 Agent 的信息和工具权限；
- 共享记忆、冲突检测和停止条件。

动手产物：加入 TimelineScout 和 EvidenceAuditor，与单 Agent 在同一测试集比较。

## S4：Reward 与环境

你需要掌握：

- 稀疏 reward 和密集 shaping 的利弊；
- 时间 IoU、证据支持率和工具成本怎样计算；
- reward hacking 可能怎样发生。

动手产物：为同一任务手算两条轨迹得分，再由环境自动复算并核对。

## S5：SFT 与 Agentic RL

你需要掌握：

- 先有可用 baseline 再训练的原因；
- 轨迹 SFT、GRPO/PPO 的输入输出；
- policy、reference、reward、KL 和 advantage；
- 为什么优先训练 Coordinator 而不是全部 Agent。

动手产物：先在小数据上过拟合并检查 reward 上升是否对应真实任务改善，再扩大训练。

## S6：评测与消融

你需要掌握：

- 按视频切分，防止同视频问题泄漏；
- 控制基础模型、工具和预算；
- 如何证明收益来自多 Agent、RL 或动态采样；
- 如何报告失败类型而不是只报平均分。

动手产物：生成统一评测表、轨迹样例和至少四项消融。

## S7：业务扩展

按顺序加入无剧透、分龄、质量增强路由和海报候选。每增加一个任务，都必须回答：

- 它复用了剧情证据图的哪些字段？
- 新增了什么工具和 reward？
- 自动标注从哪里来？
- 哪些错误必须人工复核？

## S8：工程交付与面试

最终需要能独立完成：

- 从原始视频到评测报告的复现命令；
- 数据、模型、配置和结果 manifest；
- 一次完整系统演示；
- 30 秒、2 分钟和深挖版项目介绍；
- 对每个简历数字指出对应日志和评测文件。

## 当前停点

已完成 S0 和 S1。真实样本已经形成 `media.json`、98 个镜头与关键帧、67 条标准化台词和 98 个多模态证据单元，并通过媒体、哈希、时间轴和引用关系共 10 项审计。下一步进入 S2：先定义单 Agent baseline 的输入、工具预算、输出 Schema 和轨迹格式。
