## 2. 已保留代码

### 视频选帧：`TCL 实习/frmfilter`

可确认能力：真人/动画分支、多模型感知与综合打分、黑边和质量过滤、相似帧去重、候选兜底、服务与单测脚本。

在本项目中的角色：实现 `sample_keyframes` 和 `frame_quality` adapter。先复用思想和可运行部分，不直接复制内部服务配置。

### 海外海报：`TCL 实习/poster_pipeline_cp`

可确认能力：多来源图片接入、参数标准化、筛图、裁剪、外扩、Top-K、异步任务和回调。

在本项目中的角色：后期实现 `generate_poster_candidates`；由于部分权重、网络服务和内部回调不可用，不纳入 MVP。

### 智能海报旧链路：`TCL 实习/ospip_for_align`

可确认能力：关键词搜索素材、智能裁剪、多尺寸海报、文字和 logo 修复等旧版流程说明。

在本项目中的角色：仅作为海报流程与接口设计参考，不与 `poster_pipeline_cp` 重复集成。

### 长视频增强：`TCL 实习/FlashVSR_code`

可确认能力：视频增强总控、长短视频分流、分段、重叠处理、拼接、补帧、原音频回填、批处理脚本和运行日志。

在本项目中的角色：实现 `diagnose_quality`、`enhance_segment` 和 `validate_av_sync` adapter；先在小片段上验证，不直接全片推理。

## 3. PPT 有方案但没有完整留存代码

下列能力必须由 VideoOps-RL 独立实现和重新评测：

- 镜头、ASR、speaker、人脸到统一时间轴；
- 语义完整 Chunk 和全局事件聚合；
- 剧情证据图；
- 内容驱动高光与查询式片段定位；
- 行为/内容曲线融合；
- 无剧透数据权限；
- 分龄风险和解释策略。

在这些模块完成前，只能描述为“项目目标”或“正在复现”，不能描述为已完成成果。

## 4. VideoOps-RL 新增贡献

TCL 材料主要描述固定智能 Pipeline。个人项目新增的研究与工程核心是：

1. 将不同业务统一成共享剧情证据图和工具环境；
2. 将“看哪些片段、调用什么工具、是否增强、何时复核和停止”建模为序列决策；
3. 用多 Agent 分离时间搜索、剧情分析、证据审计和质量决策；
4. 用可计算 reward 优化质量—成本—安全权衡；
5. 保存完整轨迹，使失败可定位、实验可消融、简历结果可复核。
